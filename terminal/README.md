# DRONZER TERMINAL

Standalone Advanced Cyberpunk Intelligence Terminal extracted from Dronzer.

## Features
- **Real-Time Discord Bot C2**: Live status, bidirectional command pipeline, file & image processor.
- **RAT Intercept Parsers**: Telemetry parsing for connected devices, SMS/notifications, call logs, contacts, gallery listings, and GPS coordinates.
- **Firebase RTDB (RTKL)**: Real-time kernel logs tree viewer synchronized directly with Firebase.
- **Interactive Holographic Globe**: Canvas-driven 3D coordinate mapping for intercepted devices.
- **Cyberpunk Canvas HUD**: Procedurally generated HUD frames with glowing greebles, RGB flow, and scanlines.
- **Theme Engine**: Real-time RGB styling, heavy glitch slice mode, and breathing animations.

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Dev Server
```bash
npm run dev
```

Server runs on `http://localhost:3000`.
